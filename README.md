# 🚗 Site-Egood

O **Site-Egood** é uma plataforma desenvolvida para auxiliar usuários na comparação de veículos, com foco especial em calculadoras de custo de combustível e economia solar, ajudando na tomada de decisão para a compra de novos veículos.

## 🚀 Tecnologias Utilizadas

O projeto foi construído utilizando as tecnologias mais modernas do ecossistema Frontend para garantir performance, escalabilidade e uma excelente experiência de usuário.

### 🛠️ Core & Frameworks
- **React**: Biblioteca principal para construção da interface baseada em componentes.
- **Vite**: Build tool extremamente rápida para o desenvolvimento e empacotamento do projeto.
- **React Router Dom**: Gerenciamento de rotas e navegação entre páginas.

### 🎨 Estilização e UI
- **Tailwind CSS**: Framework CSS utilitário para estilização rápida e responsiva.
- **Radix UI**: Primitivos de componentes acessíveis para a construção de interfaces complexas.
- **Lucide React**: Conjunto de ícones modernos e leves.
- **Framer Motion**: Biblioteca de animações para criar transições fluidas e interativas.
- **Shadcn UI**: Componentes de interface pré-estilizados baseados em Radix UI e Tailwind.

### 📊 Visualização de Dados & Cálculos
- **Recharts**: Biblioteca de gráficos para visualização de custos anuais e comparações financeiras.
- **Zod**: Validação de esquemas e tipos para garantir a integridade dos dados.
- **Lodash**: Utilitários para manipulação de dados e arrays.

### ⚙️ Ferramentas de Desenvolvimento
- **ESLint**: Ferramenta de linting para manter a qualidade e consistência do código.
- **PostCSS**: Processador de CSS para otimizar e compatibilizar estilos.
- **TypeScript**: Adicionado ao ambiente de desenvolvimento para tipagem estática e maior segurança.

---

## 📁 Estrutura de Pastas Principal

- `src/components/egood/`: Componentes específicos da lógica de negócio (Calculadoras, Seções de Veículos).
- `src/components/ui/`: Componentes de interface genéricos e reutilizáveis.
- `src/pages/`: Páginas principais da aplicação.
- `src/lib/`: Utilitários, constantes e dados de veículos (`vehicleData.js`).
- `src/assets/`: Imagens e recursos visuais dos veículos.
